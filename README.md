1925年10月31日，一则“列车员意外死亡，至今未能查明真相”的报道占据了报纸头条。

“鬼”、“恐怖传说”这样的字眼流传在大街小巷，被当做灰暗的市井生活中小小的谈资。

空醒来时，发现自己正身处一间破旧脏污的屋子。

墙上，地上，甚至自己坐着的这张破床，都有着大片暗红色的污迹。

房间内唯一的光源就是一盏闪烁的台灯，墙上好像写了什么东西，但根本看不清。

……这里是、什么地方？

奇怪，脑袋痛得要命。

关于怎么来到这里的记忆，则是一点都没有了。

得赶紧想办法出去才行……
